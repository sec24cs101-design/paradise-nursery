# Paradise Nursery Shopping Application

A beginner-friendly React shopping application for browsing houseplants and managing a shopping cart. Built with React, Redux Toolkit, React Redux, React Router, and Vite.

## Features
- Landing page with Paradise Nursery branding and a Get Started button
- About Us page
- Plant catalog grouped into three categories
- Add-to-cart buttons that disable after adding a plant
- Dynamic cart item count
- Cart quantity increase/decrease and item removal
- Dynamic line totals and overall total
- Checkout button with a “Coming Soon” message
- Continue Shopping navigation

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.
